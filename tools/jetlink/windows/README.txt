HL Cluster / Windows 설치 도우미

지원: Windows 10/11, ajouatom/carrot-jetson R2 설치 장치, TURZX USB 계기판.
일반 JetPack 또는 새 boot-update-required 이미지에는 설치하지 않습니다.
이 패키지는 Windows 및 실제 Jetson에서 아직 최종 검증되지 않은 테스트 배포본입니다.

1. ZIP 전체를 폴더에 압축 해제하고 Start.cmd를 더블클릭합니다.
2. SSH 키가 이미 등록되어 있으면 메뉴 1. 없으면 먼저 메뉴 2.
3. 차량을 정차하고 보조 기능을 해제하고 콤마와 Jetson USB를 분리합니다.
4. Jetson과 PC를 같은 LAN에 연결하고 Jetson IP를 입력합니다. 콤마 IP가 아닙니다.
5. 첫 접속 지문은 해당 장치인지 확인하고 승인합니다. 변경 경고는 무시하지 마세요.
6. 설치 시작 후 Jetson 전원을 유지하세요. 엔진 검사에는 최대 약 20분 걸릴 수 있습니다.
7. 메뉴 3에서 결과를 확인합니다. PC 연결이 끊겨도 Jetson 설치 작업은 계속됩니다.
8. 완료 후 cluster_jetson 브랜치가 설치된 콤마와 TURZX를 Jetson에 연결합니다.
   ClusterHud는 실제 패널 종류, ClusterHudScreenMode는 0을 사용합니다.
   콤마 브랜치는 이 PC 도우미가 설치하지 않습니다.

최초 SSH 등록
- Jetson 정상 종료와 전원 완전 분리 후 SD 또는 SSD를 PC에 연결합니다.
- Windows가 포맷을 요청하면 취소합니다. 도우미는 파티션 생성/포맷을 하지 않습니다.
- CARROTSETUP FAT 드라이브가 정확히 하나 있어야 합니다.
- 새 SSH 목록이 기존 접속 키 목록을 대체하므로 유지할 공개키를 모두 선택하세요.
- 기존 setup.json의 Wi-Fi 등 다른 설정은 유지합니다. 안전한 교체가 불가능하면 중단합니다.
- 개인키는 PC 사용자 폴더에만 남습니다. ZIP이나 상대방에게 개인키를 보내지 마세요.
- 저장 완료는 등록 완료가 아닙니다. 안전 제거, Jetson 재장착, 부팅 후 실제 접속을 확인합니다.
- 공식 설명: https://github.com/ajouatom/carrot-jetson/blob/main/docs/JETSON-SSH.md

주의 사항
- OpenSSH가 없으면 Windows 선택적 기능에서 OpenSSH 클라이언트를 먼저 설치합니다.
- 조직 보안 정책이 스크립트를 막으면 관리자에게 문의하세요. 시스템 정책을 바꾸지 마세요.
- 암호로 보호한 기존 키도 사용할 수 있으며 SSH/SCP 호출 시 암호를 다시 물을 수 있습니다.
- 실패하면 메뉴 3 결과 조회를 먼저 하세요. 메뉴 4는 이전 런타임/업데이터로 복원합니다.
- 새 계기판을 유지하기 위해 Jetson 원본 자동 업데이트는 설치 중 고정됩니다. 원복하면 재개됩니다.
- 원본 릴리즈는 삭제하지 않습니다. 전원 차단 복구는 실제 장치에서 검증되지 않았습니다.
- 마지막 작업/결과는 %LOCALAPPDATA%\HLCluster에 보관합니다. 메뉴 5로 열 수 있습니다.
- 결과 파일에는 IP와 로컬 경로 등이 포함될 수 있으니 공유 전 확인하세요.
- SHA256은 손상 검사입니다. 출처 인증 서명은 아니므로 신뢰하는 배포자에게 받은 ZIP만 실행하세요.
- 서비스 실행 확인은 실제 USB 계기판 출력이나 주행 검증을 의미하지 않습니다.
