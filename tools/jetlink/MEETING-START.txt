HL Cluster 현장 준비

이 묶음은 실제 장치 검증 전 테스트용입니다. 자동 업데이트는 기본 OFF입니다.
SSD를 맥북에 연결하는 것만으로 설치가 완료되지는 않습니다.

준비물
- 실제 사용할 콤마, Jetson, TURZX, 안정적인 전원과 USB 데이터 케이블
- 맥북, 해당 SSD와 맞는 USB 인클로저
- 실제 사용할 휴대폰 핫스팟 또는 공유기
- 콤마에 접속할 수 있는 기존 SSH 접근 권한
- 유지해야 할 Jetson의 기존 공개키(.pub). 개인키를 공유하지 마세요.

오늘 할 순서
1. 콤마에 검토된 cluster_jetson 코드를 설치합니다.
2. 콤마 전용 키를 생성합니다. 개인키는 콤마에만 보관합니다.
3. Jetson 종료와 전원 분리 후 SSD를 맥북에 연결합니다. 포맷 요청은 취소합니다.
4. CARROTSETUP에 콤마 공개키와 별도 관리자 공개키를 등록합니다.
   기존 키 목록을 대체하므로 계속 사용할 공개키를 모두 포함해야 합니다.
5. SSD를 Jetson에 되돌리고 부팅합니다. 실제 로그인 성공까지 확인합니다.
6. 같은 핫스팟에서 콤마 -> Jetson 통신과 장치 키를 확인합니다.
7. 시동이 꺼진 상태에서 수동 설치, 검사, 실제 계기판 출력을 확인합니다.
8. 재부팅, IP 변경, 원복, 업데이트 취소와 통신 단절 복구를 시험합니다.
9. 모두 통과한 뒤에만 자동 업데이트를 켭니다.

그 이후
- 사용자는 콤마를 Git pull로 업데이트하고 재부팅합니다.
- 동일 네트워크에서 시동이 꺼진 상태가 확인되면 Jetson 변경분을 적용합니다.
- 주행 상태나 상태 정보 유실을 감지하면 설치를 중단하고 복구를 시도합니다.
- 검사 실패한 버전은 무한 재시도하지 않습니다. 로그 확인 후 처리합니다.
- SSH 키를 매번 챙길 필요가 없습니다. 인증 자체를 없애는 방식은 아닙니다.

주의
- 설치가 끝나기 전에는 시동을 켜거나 운행하지 마세요.
- 핫스팟에서 기기 간 통신이 차단되면 관리 연결이 안 됩니다.
- 이 기능은 인터넷 원격접속 VPN이 아닙니다. 원격으로 콤마에 직접 접속할
  방법은 별도로 확보해야 합니다. OS 부팅 불가나 전원/SSD 고장은 현장 조치가
  필요할 수 있습니다.
- 로그 공유 시 /data/hl-jetson 폴더 전체를 보내면 안 됩니다. 개인키가 있습니다.
- 이미지가 지원 대상 R2 구조와 다르면 설치를 중단합니다. 검사 우회 금지.

명령과 상세 복구 절차: MEETING_CHECKLIST.md
prepare_ssd.py는 맥북용이고, manage_jetson.py는 콤마 저장소 안에서 실행합니다.
